# СПОД. Практическая работа № 3

Вариант 7 для группы 2303. В каждом из `p` процессов сформировать набор из `p + 5` целых чисел. С помощью `MPI_Reduce` с операцией `MPI_SUM` сложить элементы с одинаковыми индексами и вывести суммы в процессе 0.

```bash
make -C lab3
mpirun -np 4 ./lab3/lab3
```

Для четырёх процессов программа выводит девять сумм: `6 10 14 18 22 26 30 34 38`.

Для отчёта нужно показать пример запуска, описать сеть Петри и сравнить время на разном числе процессов. В сети подписаны вход и возврат из `MPI_Barrier` и `MPI_Reduce`, ожидание других процессов и повторение итераций. Ускорение считают на фиксированной нагрузке как отношение времени на одном процессе ко времени на `p` процессах. В режиме задания нагрузка меняется вместе с `p`, поэтому для ускорения используется отдельная серия на 32 наборах фиксированной длины.

`python3 lab3/bench.py` запускает облегчённую серию на 1, 2 и 4 процессах и сохраняет её в `lab3/results/quick/`. Полная серия до 32 процессов включается параметром `--full`. Она может загружать все ядра, а одни только массивы занимают до 992 МиБ.
